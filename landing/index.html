What it runs today

OpenCompanion finds these on your PATH. How much it can do depends on the CLI.

  • Claude Code

    Starts sessions, watches them, and answers their approval prompts from the desktop or your phone.

  • Codex CLI

    Starts and watches sessions. Its approval prompts are answered in its own terminal.

  • OC
    OpenCode

    Starts and watches sessions. Its prompts are answered in its own terminal.

  • Gemini CLI

    Found on your PATH and listed with its version. OpenCompanion cannot start it yet.

  • Sessions you started in your own terminal show up too, read-only, with their transcript.
  • Tested on Windows 11. macOS and Linux build from the same code but are untested.
  • Your phone reaches the computer over your own network. Away from home, use a VPN such as Tailscale.
  • Web Push is not built yet, so the phone shows notifications while its page is open.

Build it on your computer

OpenCompanion is a Tauri 2 app. You need Rust (with the MSVC toolchain on Windows), Bun, and at least one supported CLI on your PATH.

git clone https://github.com/yusupsupriyadi/opencompanion.git
cd opencompanion
bun install
bun run tauri build

The installer lands in src-tauri/target/release/bundle. For a window with hot reload, run bun run tauri dev instead.
