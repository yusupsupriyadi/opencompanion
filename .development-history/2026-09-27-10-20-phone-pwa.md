# Installable phone companion (PWA)

## Summary

The phone pages under `/m` can go on the home screen and open without browser bars: a web app manifest, Apple tags, safe-area insets and a service worker scoped to `/m` that keeps the app shell where the browser allows one. The desktop window is unchanged.

## Changes

- `static/m/manifest.webmanifest`, `static/m/icons/*`: `start_url`/`scope` `/m`, standalone, cream `#FBF3CF`; icons 192/512 any, 192/512 maskable (mark in the 80% safe circle on cream), 180 apple-touch-icon, all resized from `src-tauri/icons/icon.png` with Pillow (not kept in the repo).
- `src/routes/m/+layout.svelte`: head tags (manifest, theme-color light/dark, Apple capable, status bar `default`, title, touch icon); sets `viewport-fit=cover` on mount and restores it on leave; calls `registerWorker()`.
- `src/service-worker.ts`, `src/lib/sw-routes.ts`: SvelteKit's own service worker (`register: false` in `svelte.config.js`, precache = build files without `.woff` + phone static files). Pages network-first into one `/m` shell key; `/api/*`, non-GET, cross-origin and `Authorization` requests are never answered or stored.
- `src/lib/phone.svelte.ts`: `registerWorker()` (secure context, not Tauri), `iosHomeScreen()`. Pair screen: typed-code wording and "iPhone · Home Screen" name there.
- `src/lib/phone.css`: `.bar` and `.content` take the top/bottom insets; `100dvh`.
- `src-tauri/src/companion.rs`: `content_type()` serves `.webmanifest` as `application/manifest+json` and `.js`/`.mjs` as `text/javascript` (Tauri guesses `text/html` for unknown extensions).

## Decisions

- Service worker at `/service-worker.js`: the root covers scope `/m` (and `/m` itself, which `/m/` would not), so no `Service-Worker-Allowed` header.
- Status bar `default`, not `black-translucent`: white status text would sit on the cream Day theme.
- No HTTPS added; options left to the owner.

- `cargo test` in the shared tree (with another agent's Chat work in progress): 85 unit + 16 integration passed. The committed tree alone, checked out under %TEMP%: 80 unit + 15 integration passed; the 4 `projects::` tests only fail there, since discovery skips %TEMP% on purpose.
- `cargo clippy --all-targets`: clean on the committed tree; the shared tree has one warning in the other agent's new test (`tests/companion.rs` ~636).

## Limitations

- On the plain-HTTP LAN no service worker runs and Chrome shows no install prompt; the installed app needs the desktop to open. iOS Add to Home Screen works.
- The icon is still Tauri's default logo, as are the desktop icons. The installed app is bound to the LAN address it was added from.
- Not tried on a real phone (no smoke test requested).
