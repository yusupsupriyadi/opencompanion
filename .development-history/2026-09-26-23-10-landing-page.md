# Scroll-driven landing page

## Summary

`landing/index.html` is a one-file landing page that tells "a working day with OpenCompanion" as you scroll: the owner's meadow painting goes from morning to night while Chat, the Overview rows, the phone's Approve and the Board play out as rebuilt app components. After dark the page lists what each CLI can do today and how to build the app. Opens by double-click (`file://`); GSAP 3.13 and Google Fonts come from CDNs.

## Changes

- `landing/index.html`: sticky stage + GSAP ScrollTrigger timeline, a depth camera over three painting planes, sky states from DESIGN.md colours, canvas-tinted grades, foreground grass, lantern, stars, fireflies, a clock + horizon HUD, facts and build sections, a copy button. Static stacked layout for reduced motion, no script or a CDN failure.
- `landing/assets/meadow-{sky,clouds,ground}.webp`: `static/meadow-day.png` split into sky, clouds (colour unmixed from the blue, tree holes filled) and ground (edge colour cleaned).
- `README.md`: layout row for `landing/`.

## Decisions

- Concept "one day on the meadow", English only, CTA to the GitHub repo plus build commands, CLI logos from `design/logos` (all chosen by the owner).
- Clouds sit at the ground's depth: any parallax between them shows the sky the painting never had behind the trees.

## Verification

- BrowserOS Neo, with approval: key frames at 3440x1305, 1440x900, 1280x720 and 390x844, static mode at desktop and phone width; full scrub 0 to 100 and back with no errors; nav, skip, hero CTA, footer links, copy error path; no horizontal overflow.

## Limitations

- The GitHub repo is private, so its links fail for visitors until it is public. Copy success not seen (the background test tab had no focus).
