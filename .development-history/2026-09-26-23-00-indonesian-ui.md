# English or Indonesian UI (FR-63)

## Summary

Settings › Language switches every desktop screen, the phone page, OS notifications and the tray menu between English and Bahasa Indonesia, without a restart. Six parallel agents moved 857 strings into typed per-area dictionaries (shell 114, sessions 146, chat 96, work 176, settings 153, phone 172), each owning distinct files; the lead integrated them.

## Changes

- `src/lib/i18n.svelte.ts`: `t` fills placeholders in one pass with a function (a "$&" in a title or a "{cli}" inside a value stays as written; found by the agents), `tb` for backend text.
- `src/lib/i18n/<area>.ts`: English kept character for character, so the English tests still pass; Indonesian typed against it.
- `src/lib/format.ts`: statuses, modes, signals, durations and dates follow the language (getters keep the export shapes).
- Every screen: backend-written text (errors, a session's last event, a card's problem, transcript notes, planner error replies) is shown through `tb()`; comparisons keep the English text.
- Settings: "Language" card. `src/lib/phone.css`: phone buttons may wrap, so "Run in {folder}" cannot overflow a 320 px screen.
- Tests: one Indonesian test per area, `src/lib/i18n.test.ts`, `src/lib/i18n/backend.test.ts`. PRD FR-63, DESIGN §13, README.

## Verification

- `bun run check`: 0 errors, 0 warnings. Vitest: 145 passed (28 files); `cargo test`: 83 unit + 15 integration passed.

## Limitations

- Not looked at in the running app (no smoke test requested); longer Indonesian labels were checked against widths by reading the CSS only.
