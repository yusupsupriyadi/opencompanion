# Remove the Board

## Summary

The owner asked to take the whole Board feature out of the product. The desktop Board, the phone Board tab, Add to board in Chat, the Board card on the Session screen, running a card from the phone, and the automatic move of a card to Done are gone.

## Changes

- `src-tauri/src/{db,actions,session,lib,companion,orchestrator}.rs`: `Task`, the task store, `card_to_board`/`move_task`/`run_task`, `Emit::tasks_changed`, `task_id` on sessions, start requests and chat cards, the six Tauri commands and the `/api/tasks*` and `/api/chat/cards/board` routes removed.
- `src-tauri/tests/*.rs`: Board steps dropped; new `a_database_from_the_board_days_still_opens_and_saves_sessions` test.
- `src/routes/board/`, `src/routes/m/board/`: deleted. Sidebar and phone tab bar lose Board; Chat cards keep Run, Edit, Discard; `/m/new` keeps `?cwd=` only.
- `src/lib/i18n/*`, `app.css`, `phone.css`, `static/m/manifest.webmanifest`: Board strings and styles removed.
- Docs (README, DESIGN.md, PRD, CHANGELOG, CONTRIBUTING, SECURITY, issue templates), `landing/index.html`, `e2e/linux/e2e.py`: Board removed; PRD section H, F5, D10 and D10/M7 in DESIGN.md kept as "removed" stubs.

## Decisions

- Old databases keep their `tasks` table and `sessions.task_id` column untouched; nothing reads them, so no data is dropped.
- Old sessions whose source is `board` show no source label.

## Verification

- `cargo clippy --all-targets`: no warnings. `cargo test --lib`: 139 passed. `--test manager`: 12 passed. `--test companion -- --test-threads=1`: 5 passed.
- `bun run check`: 0 errors. `bun run test`: 210 passed. `bun run build`: ok. `python -m py_compile e2e/linux/e2e.py`: ok.

## Limitations

- Landing page: the Board scene is gone, leaving a text gap around 62 to 78 on the scroll timeline; not checked in a browser.
- Two companion tests time out (5 s read) when every test binary runs in parallel on this machine; they pass run serially.
