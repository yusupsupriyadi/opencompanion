# Meadow background fills the window

## Summary

The owner asked for the background painting to fill the window. The new `static/meadow-day.png` is 3824 x 1632 (about 2.34:1), so `contain` left wide blurred bands above and below it in a normal window. The desktop shell and onboarding now use `cover`, anchored at 70% bottom so the figure on the log (about 77% across) stays in view.

## Changes

- `src/app.css`: `.app::after` paints the painting `cover` with `--bg` under it; the blurred `.app::before` copy is gone, cover leaves no band to fill.
- `src/routes/onboarding/+page.svelte`: `.scene-art` is `object-fit: cover`; the blurred `.scene::before` copy is gone.
- `DESIGN.md`: background rule now says fill (edges may crop, never stretched) and lists the new 3824 x 1632 size.

## Decisions

- This reverses the 2026-09-27 "never cropped" rule at the owner's request.
- The phone header (`src/lib/phone.css`) is left as is: it is a header image, not the background.

## Verification

- `bun run check`: 0 errors, 0 warnings. `bunx vitest run`: 36 files, 201 tests passed.
- `bun run build`: ok; built CSS carries `background-size: 100% 100%, cover` and `.scene-art { object-fit: cover }`.

## Limitations

- Not viewed in the Tauri window; no smoke test was requested.
- The phone header still uses the old 1672 / 941 box ratio, so the wider painting leaves a `--bg` band above it.
- The new `static/meadow-day.png` is not part of this commit; it is still an uncommitted change in the tree.
