# Fit the background painting instead of filling

## Summary

The owner saw the painting as zoomed: `cover` cropped about 10% of its width in the default 1280 x 800 window and enlarged it 1.15x when maximized. After trying stretch, the owner chose fit, so the painting now shows whole.

## Changes

- `src/app.css`: `.app::after` draws the painting with `contain` (70% bottom) under the haze; `.app::before` fills the leftover band with the same painting, cover-scaled and blurred 32px (inset -48px so the blur has no faded edge). Day `--art-filter` is `brightness(1)` so it can follow `blur()` in one filter list.
- `DESIGN.md`: background line describes the fit layout.

## Decisions

- The band shows a blurred copy of the painting rather than a flat bar; a cream bar against the deep blue sky would read as a gap.

## Verification

- Pixel simulation of the fit layout, 1100 to 2560 wide: glass `ink-2` worst 4.63 to 4.77 in both themes, unchanged from before.
- `bun run check`: 0 errors. `bun run build`: ok. `bun run test`: 105 passed.

## Limitations

- Not viewed in the running app. Onboarding art still uses `object-fit: cover`.
