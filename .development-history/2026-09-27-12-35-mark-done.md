# Mark an idle terminal session done

## Summary

An interactive session whose CLI finished its turn sat at Idle forever; the only way out was Stop, which recorded it as Stopped. A new Mark done action closes the CLI the same way but ends the session as Done.

## Changes

- `src-tauri/src/session.rs`: `mark_done`/`mark_done_from` share Stop's shutdown through `end`; a `done_requested` flag makes the exit count as Done ("Marked done by you"); Done or Stop from the user sends no "finished" notification.
- `src-tauri/src/lib.rs`, `src-tauri/src/companion.rs`: `mark_session_done` command and `POST /api/sessions/{id}/done` for the phone.
- `src/routes/session/+page.svelte`, `src/routes/m/session/+page.svelte`: Mark done button (primary on desktop, `check` icon on the phone) shown only for an Idle interactive session.
- `src/lib/api.ts`, `src/lib/i18n/*`: API call and English/Indonesian copy, including the new backend notes.
- `DESIGN.md`: session header specs mention Mark done.

## Decisions

- Mark done appears only at Idle, so a CLI mid-turn is never closed as "done"; Stop still covers that.
- No confirmation sheet on the phone: Resume reopens the conversation, unlike an accidental Stop's intent.
