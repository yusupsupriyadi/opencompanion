# Pin folders and sessions in the sidebar

## Summary

Owner asked for a pin feature and chose both folders and sessions. Pinned folders lead the Sessions list even with no recent session; pinned sessions always show, first in their folder, on top of the six most urgent others.

## Changes

- `src/lib/Sidebar.svelte`: `air-pinned-folders` (paths) and `air-pinned-sessions` (ids) in `localStorage` via shared `readList`/`saveList`/`flip` (collapsed folders reuse them); `folderKey` helper; group builder adds pinned folders first and pinned sessions outside the six cap; `push-pin` toggle (`aria-pressed`) on folder heading and session rows next to `plus`/`trash` in one `.row-actions` overlay; "No recent sessions" for an empty pinned folder.
- `src/lib/Sidebar.test.ts`: pinned session survives the six cap and a remount; pinned folder stays when empty, offers New session, unpins.
- `DESIGN.md`: Sidebar spec, icon list.

## Decisions

- Pins are desktop-local (like collapsed folders), not synced to the phone.
- Row buttons overlay the row end on hover/focus instead of reserving space, so titles keep their width; an active pin stays visible and reserves 36 px.
- Unpinned folders still order by their most urgent session.

## Verification

- `bun run test`: 85 passed. `bun run check`: 0 errors, 0 warnings. `bun run build`: ok.

## Limitations

- A pinned session shows only while it is among the 80 most recent sessions the app loads.
- Not clicked through in the running app (no smoke test requested).
