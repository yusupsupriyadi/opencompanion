# App logo

## Summary

OpenCompanion has its own logo, replacing Tauri's default icon and the Phosphor cloud next to the wordmark. The owner picked "Bukit piksel" from three concepts (Pendaki, Garis horizon, Bukit piksel): the meadow hill in `forest` on a `bg` sky, with the blue-jacket hiker drawn in pixels on the ridge.

## Changes

- `design/logo.svg`, `design/logo-full.svg`: sources (rounded tile; full-bleed for maskable and apple-touch).
- `src-tauri/icons/*`: regenerated with `tauri icon` into a temp folder, only the existing file names copied (no android/ios folders). The tray uses the window icon, so it follows.
- `static/m/icons/*`, `static/favicon.png`: same sizes as before, rendered with `tauri icon -p`.
- `src/lib/AppLogo.svelte`: inline logo (no clipPath, so no id clash); used before the wordmark in the sidebar, onboarding and the four phone top bars.
- `landing/index.html`: favicon, `#i-logo` symbol in place of `#i-cloud`, brand icon 24.
- `DESIGN.md`: logo subsection in section 5, brand sizes, file list, decision line.

## Decisions

- Figure on a 16-unit grid so it stays sharp at 16 and 32 px.
- No `OC` monogram: CliMark already uses it for OpenCode.

## Verification

- `bun run check`: 0 errors. `bun run test`: 32 files, 179 passed. `bun run build`: ok. `cargo check`: ok.
- Rendered previews at 256 to 16 px on light and dark taskbars, the lockup on Day and Dusk sidebar colours, and the maskable crop inside the 80% safe circle.

## Limitations

- The app was not run (no smoke test requested); tray and taskbar icons not seen live.
