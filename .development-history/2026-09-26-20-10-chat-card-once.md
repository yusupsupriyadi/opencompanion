# Add to board makes one Board card, and Run starts one session

## Summary

Code review found that Add to board on a Chat card could be pressed again and again, each press making another Todo card, and that a Run pressed on the phone and the desktop at the same moment could start two sessions for one card.

## Changes

- `src-tauri/src/db.rs`: `DispatchCard.task_id` (serde default, so old cards load).
- `src-tauri/src/actions.rs`: `card_to_board` records the Board card on the chat card and refuses a second while that card exists; returns the task and the message. `run_card` claims the card id for the length of the start.
- `src-tauri/src/lib.rs`, `companion.rs`: desktop command returns the message; phone endpoint returns task and message; both tell the other screens the chat changed.
- `src/lib/DispatchCard.svelte`, `PhoneDispatchCard.svelte`: after Add to board the button becomes an "On the Board" link. `api.ts` types. Tests updated and one added.
