# Board: kanban for CLI tasks

## Summary

Added a Board feature (Pending, Todo, In progress, Done) to the PRD, DESIGN.md and the OpenDesign prototype. Todo cards run straight into a CLI session and then follow that session's status.

## Changes

- OpenDesign `board.html`: four columns, compact icon-first cards (Run and Open session as top-right icons, status as icons), drag-drop moves or Column field in the card dialog, Run dialog, add/edit/delete, project filter, reset; cards stored in localStorage for the prototype.
- OpenDesign `scripts/app.js`: Board added to the sidebar nav.
- `docs/PRD.md`: section H (FR-70 to FR-77), flow F5, screen D10, `Task` data model, summary item 6.
- `DESIGN.md`: D10 spec, Board column and Task card components, icons, nav.

## Decisions

- Pending means not ready (ideas, open questions, blocked); Todo means ready to run.
- A finished session moves its card to Done automatically; an errored one stays in In progress.
- Arrow move buttons removed at the owner's request; the card dialog Column field is the keyboard path.
- Board requirements are P1 (after the desktop MVP core); easy to raise to P0.
