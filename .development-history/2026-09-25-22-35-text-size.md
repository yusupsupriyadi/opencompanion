# Text size setting

## Summary

Owner asked for adjustable text size in Settings. Settings now has a Text size card (90, 100, 110, 125, 150%) that applies at once to every desktop screen and is restored on start (PRD FR-66).

## Changes

- `src-tauri/src/db.rs`: `Settings.text_size` (default 100), `TEXT_SIZES`, `Settings::zoom()` with a 100% fallback; unit test for old settings rows and unknown values.
- `src-tauri/src/lib.rs`: `apply_text_size` sets the main webview zoom in `setup` and in `save_settings` when the size changes.
- `src/lib/api.ts`, `src/lib/format.ts`: `textSize` field, `TEXT_SIZES`.
- `src/routes/settings/+page.svelte`, `settings.test.ts`: radio card with a sized "A" per option; a failed save puts the choice back.
- `docs/PRD.md` FR-66, `DESIGN.md` section 12, `README.md`.

## Decisions

- Webview zoom instead of text-only scaling: every size in the CSS is px, so zoom keeps text, controls and spacing in proportion, and narrow windows fall back to the existing 1100/720 breakpoints. Applied from Rust, so no new JS capability is needed.
- The phone page (`/m`) is not scaled; it follows the phone's own text size.
