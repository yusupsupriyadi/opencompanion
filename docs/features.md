# Features

- Start Claude Code, Codex CLI or OpenCode in a project folder, in a real terminal (ConPTY on Windows) or headless, where the CLI's JSON output becomes a list of events. A terminal session runs in a shell (PowerShell on Windows, bash on Linux and macOS), like a terminal of your own: when the CLI exits, typing its name starts it again with the session's flags and hooks, `exit` closes the terminal, and typing into a closed one starts it again with the CLI's own history. Stop a headless session or send it a follow-up message.
- Type into a session's terminal as you would in your own. Shift+Enter adds a line, and Ctrl+V pastes text or an image; an image is saved and pasted as its file path, which Claude Code and Codex CLI attach as the image.
- See every session on one line in the Overview: status, latest event and an activity track. The sidebar lists every session under its project folder, with pinned folders and sessions first, and counts the AI CLIs running in each session's terminals ("×2" when you started Claude Code in two tabs). A session runs while a CLI runs in one of its terminals; a terminal left at its shell prompt shows "No CLI running" and can be deleted, which closes its shells. All sessions adds search and filters, and each session shows its CPU and memory use.
- Beside a session's terminal, browse its folder (ignored files in italics, a search by name or by text), read a file with syntax colors for about 40 common languages and an optional wrap for long lines, view images and PDFs (zoom, selectable PDF text, up to 50 MB), see the uncommitted changes with their diff, and see or switch the branch. It is all read-only except the switch, which waits until the session has stopped and the tracked files are committed. Desktop only.
- Sessions you opened in your own terminal show up too, read-only, with a transcript read from the CLI's own history.
- Know when a session is waiting for you. Claude Code permission prompts get Approve and Deny buttons. A CLI's opening dialogs, such as a folder trust question or an update offer, show as Waiting for you and are never answered for you.
- Get OS notifications, with choices per CLI and per project folder. On Windows, clicking one opens its session.
- Describe work in Chat, in plain words. A planner turns it into one card per session; you read each prompt, then press Run. The planner is a CLI running headless with read-only access to your project folders, or any OpenAI-compatible endpoint such as Ollama, LM Studio or OpenRouter. Type `@` to name a folder, and pick the planner's model and thinking level. In folders you choose, cards may start without Run, but never in Bypass mode. Ask for something that should repeat ("every weekday at 9, review the open pull requests in uninote") and the planner answers with an automation card that shows its schedule; Create saves it as an automation, and such a card never saves itself, not even in those folders.
- Schedule sessions in Automations (sidebar, and a tab on the phone): a name, a CLI, a folder, a prompt, a permission mode and a schedule (every day, some days, every few minutes or hours, or a cron expression, in this computer's local time). OpenCompanion starts the session by itself while it is open or in the tray; a run missed while it was closed runs once when it opens again, marked Late, and a run is skipped while the last session it started still runs a CLI. Each automation keeps its last 50 runs, and Run now starts one at once.
- Run the project itself from its session: New terminal (the `+` after the session's tabs) opens a plain shell such as PowerShell, Command Prompt, Git Bash or bash in the session's folder, one tab each, for a dev server, tests or git. Split terminal puts a shell in the tab you are looking at instead, beside the CLI or another shell, up to four per tab. Drag a tab or a split terminal's name onto any side of a terminal to split it that way, one split inside another, onto a tab to join it, or between tabs to reorder them; right-click a tab, or click a split terminal's name, to swap, dock or move terminals without dragging. Right-click inside a terminal to copy, paste, clear or restart it, open a new terminal tab or split it right, left or down. A tab's right-click menu closes it, the others, those to its right or all of them (pinned tabs stay), and renames, pins, duplicates, clears or restarts it; Ctrl+PageUp and Ctrl+PageDown switch tabs and Ctrl+Shift+W closes one. Shells keep no history, end when you close their tab or delete the session, and are reachable from the desktop only, never from the phone.
- Compare the skill folders of each CLI in Settings › Skills: which skill is missing from a CLI's folder or has different content there, with a command to copy and run yourself.
- Keep sessions running from the tray after the window closes, and start in the tray when you sign in to Windows.
- Answer from your phone on the same network: watch sessions, Approve or Deny, start new sessions, mark them done, send messages and plan in Chat. The phone page can go on the home screen.
- Pick a [permission mode](clis.md#permission-modes) per session: Ask me, Plan, Auto or Bypass.
- Settings also covers the Day or Dusk theme, text size, retention of finished sessions, custom CLI paths and the UI language.
